# StreamList

StreamList is a React-based web application created for EZTechMovie.

The application allows users to enter the name of a movie or program they want to watch. The current version uses React Router to provide navigation between four pages:

- StreamList
- Movies
- Cart
- About

The StreamList page accepts user input and displays the entered movie or program in the browser console.

## Technologies Used

- React
- JavaScript
- React Router
- CSS
- Visual Studio Code
